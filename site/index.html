How it works

Three mechanisms. Each was measured on macOS 15.6 before being relied on.

Finding

No permission needed

Owner name, bounds and the on-screen flag were never TCC-gated — only window titles were. Querying with .optionAll is what makes dropped items visible to the app at all.

Placing

Rightmost slot available

A preferred-position value written before the item is created lands the chevron beside Control Center. The value counts from the right edge, so smaller sorts further right.

Hiding

Geometry, not trickery

An empty item that grows shifts the whole run leftward, and the window server culls whatever crosses the notch. Instant and reversible, because nothing is being intercepted.

The number that can delete the app

The shift applies to every third-party item — including Overflow's own chevron. So the length is clamped against a live reading of where the chevron actually is, never a stored or assumed one.

What it looks like

One chevron in the bar. Everything macOS dropped, listed with the icon of the app that owns it.

Permissions

Overflow runs with none. Finding, listing and hiding items need nothing at all.

Accessibility is optional and buys exactly one thing: clicking an entry presses the real status item so its own menu opens. Decline it and clicking reveals the item in the bar for eight seconds so you can click it yourself.

Screen Recording is never requested. Other menu bar managers need it because they redraw other apps' status-item images; Overflow draws the owning app's bundle icon instead. Nothing is collected and nothing leaves your Mac.

What it doesn't do

Stated here because they're real, and you'd find them in the first ten minutes anyway.

  • Click-through coverage is partial. Items backed by a standard menu respond. Items that consume the mouse event themselves don't — and that's architectural, not positional. Those fall back to reveal-and-click.
  • Hiding leaves a gap. Space has to go somewhere when items are displaced. Avoiding it would mean drawing our own bar, which is what forces other tools into requiring Screen Recording.
  • The chevron costs a slot. On a completely full bar it evicts one item — which then shows up in the menu, still reachable.
  • Not notarized. First launch needs a right-click, then Open.
