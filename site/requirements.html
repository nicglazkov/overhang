Requirements

For Overhang 0.5.3. Last updated 2 August 2026.

System requirements

Operating system macOS 14 Sonoma or later
Hardware Apple silicon or Intel, universal binary
Disk space Under 2 MB
Network Not required
Permissions None to install or run. Accessibility is asked for only if you enable click-through

Display compatibility

Notched Macs

Fully supported, this is where Overhang helps most. The notch removes a section of usable menu bar, so the bar fills up sooner and icons start disappearing earlier.

Macs without a notch

Fully supported. A full menu bar drops icons on any Mac, the notch simply makes it happen with fewer icons.

External displays

Supported. Overhang reads the usable region from the active display rather than assuming a fixed size, and recalculates when the display arrangement changes.

Building from source

Xcode 15 or later
Swift 5.9 or later, included with Xcode
XcodeGen Required. Install with brew install xcodegen
Dependencies None. Apple system frameworks only
Signing Ad hoc by default

Known limitations

Click through does not reach every item

Items built on a standard menu open directly. Some applications handle the mouse event themselves and ignore anything else, so clicking those brings the owning application to the front instead. This depends on how each application was written.

Adding the control costs a slot

On a completely full bar, Overhang's own icon displaces one existing icon. That icon then appears in Overhang's menu, so it stays reachable.
