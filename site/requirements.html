Display compatibility

Notched Macs

This is where Overhang helps most. The notch removes a section of usable menu bar, so the bar fills up sooner and icons start disappearing earlier.

Macs without a notch

Fully supported. A full menu bar drops icons on any Mac, the notch simply makes it happen with fewer icons.

External displays

Supported. Overhang reads the usable region from the active display rather than assuming a fixed size, and recalculates when the display arrangement changes.

Known limitations

Click through does not reach every item

Items built on a standard menu open directly. Some applications handle the mouse event themselves and ignore anything else, so those fall back to being revealed in the bar for you to click by hand. This depends on how each application was written.

Adding the control costs a slot

On a completely full bar, Overhang's own icon displaces one existing icon. That icon then appears in Overhang's menu, so it stays reachable.
