Privacy Policy

Applies to Overhang for macOS, all versions. Last updated 1 August 2026.

The short version

Overhang collects nothing, sends nothing and stores nothing about you. It has no analytics, no account system and no server. This page explains that in more detail, but there is no caveat hiding further down.

Information we collect

Personal information

None. Overhang never asks for your name, email address or any other identifying detail, and has nowhere to send them if it did.

Usage data and analytics

None. There is no usage reporting, no crash reporting, no event tracking and no device or installation identifier.

Cookies and similar technologies

The app is not a web application and sets no cookies. This website stores exactly one value in your browser, a light or dark theme preference, so the page does not change appearance between visits. It is local to your browser, contains no identifier, and is never transmitted.

What the app reads on your Mac

To do its job, Overhang reads the position, size and owning application of the icons in your menu bar. This is how it works out which icons macOS has stopped drawing.

That information is used in memory, on your Mac, and is discarded when the app quits. It is never written to a log, never sent anywhere, and never shared with anyone.

What is saved between launches

Two preferences: how much of the bar you have chosen to hide, and whether you enabled launch at login. Both are stored in the standard macOS preferences file for the app and never leave your Mac.

Permissions

Accessibility, optional

If you turn on click through, Overhang uses the Accessibility API for a single purpose: pressing a status item that you selected from its menu. It does not read screen contents, does not read keystrokes, and does not inspect other applications beyond the menu bar item you asked it to open.

You can decline this permission and keep using the app. Overhang will reveal the hidden item in the bar instead so you can click it yourself.

Screen Recording, never requested

Overhang does not request Screen Recording under any circumstances. Some menu bar utilities need it because they redraw other applications' icons, which requires capturing the screen. Overhang reads each application's own icon from its bundle instead.

Network access

Overhang makes no network requests. It does not check for updates, does not phone home, and contains no third party SDKs, advertising libraries or analytics frameworks.

You can verify this. The full source is published, and macOS itself will confirm the app holds no outgoing connections.

Third parties

There are none. No data is shared, sold or disclosed to anyone, because none is collected.

This website is hosted on GitHub Pages. GitHub may keep standard server logs for requests to it, which is outside our control and covered by GitHub's privacy statement. Downloading a release from GitHub is likewise subject to their policy.

Children

Overhang is a utility with no accounts, no content and no data collection, so it is suitable for all ages and collects nothing from anyone regardless of age.

Changes and contact

If this policy ever changes, the updated date at the top will change with it and the revision will be visible in the repository history.

Questions about privacy can be raised as an issue on GitHub.
